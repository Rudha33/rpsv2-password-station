# rudha's password station
rudha's password station - RPS v2 is a Password Station is a command-line utility designed for generating and evaluating secure passwords made by rudha33 (aka rudha). It provides tools to create random passwords of user-defined length, 
generate cryptographic hashes (MD5 and SHA-256), and assess password strength based on complexity criteria such as length, use of uppercase letters, numbers, and special characters. All generated data is stored locally in an organized output directory for later reference.
